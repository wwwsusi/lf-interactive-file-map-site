Control Center V2

Aktuálne operatívne fakty poskytuje prihlásený backend cez /api/dashboard zo Supabase. Obnova údajov nemení canonical dáta.

LIVE SUPABASE označuje živé údaje; SNAPSHOT je výslovne importovaný historický podklad a DEMO je syntetická ukážka. Pri chybe obnovy zostávajú posledné úspešné údaje označené STALE / ERROR.

Odhlásenie invaliduje serverovú session a vyčistí interné údaje z pamäte a zobrazenia. Výslovne uložený historický import odstrániš samostatnou akciou.

Drive odkazy nemenia oprávnenia ani nepotvrdzujú schválenie. Mapa a história operácií majú samostatné pokrytie; ostatné chaty a konektory sa automaticky nesledujú.

Legacy Markdown CLI a Pages reporting sú vyradené; nepoužívaj ich pre aktuálne operatívne údaje.
