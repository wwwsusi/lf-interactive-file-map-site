Ako používať dashboard

Prehľad ukazuje priority, rozhodnutia a ďalšie kroky z canonical zdrojov. Ďalšie kroky používajú rovnaké operatívne položky; dashboard nevytvára nový zoznam úloh a nič nemení v zdrojoch.

Dashboard používa ručne importovaný snapshot bez Google OAuth. Obnoviť report prepočíta iba načítané dáta; nové údaje vyžadujú nový import. Pripojenie služby obnovuje samostatne iba mapu a históriu operácií. Chyby a vek posledného úspešného čítania nájdeš v Stav zdrojov. Konflikt nerozhoduje dátum úpravy. Schválenie, publikovanie a platformové overenie sú odlišné údaje.

Detail položky obsahuje pôvod, canonical odkazy a súvisiace zdroje. Mapa zdrojov zachováva pôvodný graf, hľadanie, filtre a dôkazy. Home / Reset vymaže filtre a vráti Prehľad.

Import snapshotu je samostatná vedomá voľba: uloží JSON v IndexedDB tohto prehliadača a nikam ho neodosiela. Vymazať uložený snapshot odstráni túto kópiu. Vedomý import môže obsahovať graf, dashboard alebo oboje. Dashboard importovaný používateľom sa uloží spolu s časom a názvom súboru; údaje načítané zo služby sa trvalo neukladajú. Samotný graf nie je evidencia business faktov.

Odpojenie alebo vypršanie prihlásenia vyčistí interné údaje z pamäte a obrazovky vrátane grafu a histórie. Samostatný ručne uložený import zostáva uložený do výslovného vymazania; reload ho môže znovu načítať.

Demo používa iba označené syntetické údaje. Aktivity sledujú len zapojené adaptéry, nie automaticky všetky AI chaty. Dashboard je read-only; schvaľovanie a publikovanie zostávajú v canonical workflow.
