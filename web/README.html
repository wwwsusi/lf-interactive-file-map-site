Control Center V2

LIVE SUPABASE: prihlásený backend a ručný refresh. SNAPSHOT je explicitný historický import; DEMO je syntetické. Aktuálne operatívne fakty vlastní Supabase. Pri chybe obnovy sa zachovajú posledné úspešné údaje so STALE / ERROR.

Drive odkazy nemenia oprávnenia ani nepotvrdzujú approval. Cross-site cookie môže blokovať prehliadač. Aktuálny návod vlastní README v repozitári.

Historický návod — staršie režimy

Prehľad ukazuje priority, rozhodnutia a ďalšie kroky z canonical zdrojov. NEXT vyberá najviac päť konkrétnych krokov z NOW podľa doloženej priority; celý NOW register je samostatný pohľad. Dashboard nemení zdroje.

Dashboard používa ručne importovaný snapshot bez Google OAuth. Obnoviť report prepočíta iba načítané dáta; nové údaje vyžadujú nový import. Pripojenie služby obnovuje samostatne iba mapu a históriu operácií. Chyby a vek posledného úspešného čítania nájdeš v Kvalite dát. Konflikt nerozhoduje dátum úpravy. Schválenie, publikovanie a platformové overenie sú odlišné údaje.

Detail položky obsahuje pôvod, canonical odkazy a súvisiace zdroje. Mapa zdrojov zachováva pôvodný graf, hľadanie, filtre a dôkazy. Home / Reset vymaže filtre a vráti Prehľad.

Import snapshotu je samostatná vedomá voľba: uloží JSON v IndexedDB tohto prehliadača a nikam ho neodosiela. Vymazať uložený snapshot odstráni túto kópiu. Vedomý import môže obsahovať graf, dashboard alebo oboje. Dashboard importovaný používateľom sa uloží spolu s časom a názvom súboru; údaje načítané zo služby sa trvalo neukladajú. Samotný graf nie je evidencia business faktov.

Odpojenie alebo vypršanie prihlásenia vyčistí interné údaje z pamäte a obrazovky vrátane grafu a histórie. Samostatný ručne uložený import zostáva uložený do výslovného vymazania; reload ho môže znovu načítať.

Demo používa iba označené syntetické údaje. Aktivity sledujú len zapojené adaptéry, nie automaticky všetky AI chaty. Dashboard je read-only; schvaľovanie a publikovanie zostávajú v canonical workflow.
